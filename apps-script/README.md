# 상담 신청 접수 설치 방법 (약 5분)

1. https://sheets.google.com 에서 **새 스프레드시트** 생성 (이름 예: 상담신청 접수)
2. 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 기본 코드를 모두 지우고 `Code.gs` 내용을 붙여넣기 → 저장
   - 이메일 알림을 받으려면 `NOTIFY_EMAIL`에 본인 이메일 입력
4. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** 클릭 후 권한 승인 (고급 → 안전하지 않은 페이지로 이동 → 허용)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 복사
6. `script.js` 6번째 줄에 붙여넣기:
   `const LEAD_ENDPOINT = "복사한 URL";`
7. 커밋/푸시하면 홈페이지에서 신청이 시트에 쌓입니다.

※ 코드를 수정하면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다(URL은 유지).

## 새소식&이야기 게시판 (관리자 전용 글쓰기)

1. Apps Script 왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**
   - 속성: `ADMIN_PASSWORD`, 값: 원하는 관리자 비밀번호 (코드나 GitHub에는 적지 않습니다)
2. 코드를 갱신했으므로 **배포 → 배포 관리 → 새 버전**으로 다시 배포합니다(URL 유지).
3. 홈페이지 하단 **새소식&이야기**의 `관리자` 버튼 → 비밀번호 입력 → 글 등록/삭제.
   - 글은 같은 스프레드시트의 `새소식` 시트에 저장되며, 시트에서 직접 수정해도 됩니다.
   - 비밀번호는 서버에서 확인하며, 5회 연속 틀리면 10분간 로그인이 차단됩니다.
